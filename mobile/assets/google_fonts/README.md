# Phông đóng gói

Be Vietnam Pro (Regular, Medium, SemiBold, Bold) và Lora (Regular, SemiBold), giấy phép SIL Open Font
License 1.1, lấy từ kho Google Fonts. Đặt ở đây để `google_fonts` đọc từ tài nguyên ứng dụng thay vì
tải từ fonts.gstatic.com mỗi lần mở (`GoogleFonts.config.allowRuntimeFetching = false` trong
`main.dart`) — mất mạng vẫn đúng phông, và không có lượt gọi ra ngoài nào không cần thiết.
